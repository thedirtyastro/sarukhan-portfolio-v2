# Sarukhan Portfolio (Next.js)

Next.js 15 App Router · React 19 · TypeScript · Tailwind CSS 3 · GSAP

    npm install
    npm run dev      # http://localhost:3000
    npm run build

- Project data: `data/projects.ts` (23 projects, one line each)
- Contact/skills/services: `data/site.ts`
- Styles: `app/globals.css` (design tokens in `:root` and `tailwind.config.ts`)
- Animations: `components/Motion.tsx` (GSAP, respects prefers-reduced-motion)
